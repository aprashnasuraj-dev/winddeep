**Ranking rationale:** Preserve all P0/P1 operations exactly ahead of research. Session-state evidence reuse offers the shortest path to high-impact authorization detection; authority-drift evidence is next because a catalogued SSRF wrapper alone does not verify this parsing edge case. Generic triage and chain work follow, and extension bridge analysis ranks last because it is more specialized and expensive. Counterexample: a cacheable public endpoint returning 200 after deactivation is *not* a session-revocation bug; a URL whose destination is explicitly permitted to change is *not* SSRF. Require evidence and negative controls.

**Execution boundary:** Only Docker/localhost-owned OWASP Juice Shop, DVWA, WebGoat, crAPI or isolated synthetic fixtures with explicit authorization. All scope, signed consent, live preflight, rate, redaction, encryption, evidence-integrity, program-policy, and audit gates remain intact. No public-target testing, new attack payloads, or automatic privilege-changing actions are authorized by this backlog. Do not merge this stacked documentation PR before reviewing parent #23.
